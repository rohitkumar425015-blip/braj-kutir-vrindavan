# Braj Kutir — Vrindavan Real Estate

Premium real estate presentation site for Braj Kutir, focused on residential, commercial, plots and investment opportunities in Vrindavan.

## Run locally

This is a PHP-compatible site. If PHP is installed:

```powershell
php -S localhost:8080 -t .
```

The homepage is `index.php`.
